# Асинхронний TCP-чат

Рішення `SocketChat.sln` містить:

- `ChatProtocol` — спільні класи JSON-протоколу;
- `ChatServer` — асинхронний TCP-сервер на порту 5000;
- `ChatClient` — WinForms-клієнт.

Клієнт першою командою передає юзернейм. Сервер зберігає історію повідомлень
із послідовними ідентифікаторами. Команда `update` передає ідентифікатор
останнього отриманого повідомлення, тому сервер повертає лише нові записи.
Приєднання та від'єднання користувачів додаються до історії від імені
`Система`.

## Запуск

Потрібні Windows і .NET 8 SDK. Спочатку запустіть сервер:

```powershell
dotnet run --project .\ChatServer\ChatServer.csproj
```

Потім запустіть один або кілька клієнтів:

```powershell
dotnet run --project .\ChatClient\ChatClient.csproj
```

Для клієнтів на іншому комп'ютері введіть IP-адресу сервера та дозвольте TCP
порт 5000 у брандмауері Windows. Сервер зберігає історію в оперативній пам'яті
до завершення процесу.

# Екзаменаційне завдання — чат із виділеним сервером

Обрано перший варіант екзаменаційного завдання. Рішення `ExamChat.sln` містить:

- `ChatProtocol` — спільні класи JSON-протоколу;
- `ChatServer` — консольний асинхронний TCP-сервер;
- `ChatClient` — WinForms-клієнт.

## Можливості

- реєстрація та вхід користувачів;
- безпечне зберігання паролів як PBKDF2-SHA256 хешів з індивідуальною сіллю;
- збереження облікових записів і груп у `chat-server-data.json`;
- список користувачів онлайн;
- особисті повідомлення між користувачами;
- створення групового чату;
- приєднання до наявної групи;
- повідомлення всім онлайн-учасникам групи;
- системні повідомлення про вхід і вихід користувачів;
- підтримка багатьох одночасних клієнтів.

Повідомлення передаються через TCP як UTF-8 JSON, по одному JSON-об'єкту в
рядку. Кожний запит має `RequestId`; це дозволяє клієнту відрізняти відповідь
на команду від асинхронного вхідного повідомлення.

## Запуск

Потрібні Windows і .NET 8 SDK. Спочатку запустіть сервер:

```powershell
dotnet run --project .\ChatServer\ChatServer.csproj
```

Потім запустіть декілька клієнтів:

```powershell
dotnet run --project .\ChatClient\ChatClient.csproj
```

Сервер слухає TCP-порт `5004`. Для перевірки зареєструйте щонайменше двох
користувачів у різних вікнах клієнта. Для групового чату один користувач створює
групу, а інший обирає її у списку та натискає **Приєднатися**.

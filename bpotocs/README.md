# Багатопоточність — шифр Цезаря

Рішення містить два застосунки:

- `CaesarConsole` — консольний застосунок;
- `CaesarWinForms` — застосунок Windows Forms.

Обидва застосунки читають текстовий файл у UTF-8, шифрують латинські та
українські літери в окремому робочому потоці й записують результат
поруч із початковим файлом з суфіксом `_encrypted`. Пробіли, цифри та розділові
знаки не змінюються. У разі скасування незавершений тимчасовий файл видаляється.

## Запуск

Потрібні Windows і .NET 8 SDK або Visual Studio 2022 з компонентом
`.NET desktop development`.

Відкрийте `Bpotocs.sln` у Visual Studio, виберіть потрібний стартовий проєкт і
натисніть `F5`.

З командного рядка:

```powershell
dotnet run --project .\CaesarConsole\CaesarConsole.csproj
dotnet run --project .\CaesarWinForms\CaesarWinForms.csproj
```

У консолі шифрування скасовується клавішею `C` або `Ctrl+C`. У WinForms для
цього передбачено кнопку **Скасувати**.
